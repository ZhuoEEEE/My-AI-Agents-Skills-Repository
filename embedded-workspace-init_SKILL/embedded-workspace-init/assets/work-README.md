# Workstreams

用途：保存每个逻辑任务的状态、说明、工具和产物。建立任务不复制工程；修改、生成或构建前才检出指定完整工程及共享依赖。

- 所有者：workstream metadata and source-private Git
- Agent 管理 Git：metadata tracked; source bodies ignored
- 释放规则：正式完成时检查并释放工程副本，也可指定任务和工程单独释放。暂停、未解决修改、待同步及实际目录引用会阻止相应释放。
- 保留内容：任务记录、报告、其它产物、源码分支与提交。工程内独有产物先转存并校验，共享文件保留到最后一个使用者释放。

工程副本由管理脚本维护，不能直接删除工程目录或源组私有 Git。
